# 서동과 선화공주 — 원전 근거 (차상찬 «해동염사» 선화공주 장 + 삼국유사 무왕조)

원문 확보: works/sources/seodong_seonhwa_ko.txt (해동염사 국문 1,102자).
정사 전거: 삼국유사 기이 무왕조 — 서동요 향가의 출전.

- 서동(薯童): 백제의 못가에서 마(薯)를 캐어 파는 소년. 총명하고 담대함.
- 신라 진평왕의 셋째 선화공주가 곱다는 소문 → 서라벌로 가 아이들에게 마를
  나눠 주며 노래를 퍼뜨림(서동요). 각색: 노래 내용은 "공주가 서동을
  좋아한다더라"의 짓궂은 놀림 수준으로 순화(아이 안전).
- 노래가 대궐에 닿아 공주가 귀양 → 귀양길에 서동이 나타나 동행·혼인.
- 공주의 금 한 덩이에 서동이 웃으며 "마 캐던 곳엔 흙처럼 쌓였다" — 금
  골짜기. 금을 신라로 보내 인심을 얻고 서동은 백제 무왕이 된다.
- 유보(withheld): 미륵사 창건 설화(못에서 솟은 미륵)와 왕비 선화의 발원.
- 이중 상태 분리: 공주(궁중/귀양길), 규칙 전체 적용, 화풍은 검증 민화.
