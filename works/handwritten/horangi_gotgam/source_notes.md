# 호랑이와 곶감 — 원전 근거 (한국 전래동화)

- 겨울밤 굶주린 호랑이가 마을로 내려와 외양간에 숨는다.
- 방 안에서 아기가 운다. "호랑이 왔다" 해도 그치지 않던 울음이
  "곶감이다" 한마디에 뚝 — 호랑이는 곶감을 저보다 무서운 짐승으로 여긴다.
- 소도둑이 어둠 속에서 호랑이를 살진 소로 착각해 등에 올라탄다.
- 호랑이는 '곶감이 붙잡았다' 여겨 밤새 내달리고, 도둑은 새벽에
  나뭇가지를 붙들고 겨우 벗어난다. 둘 다 혼비백산 — 완결형 희극.
- 물증: 처마 밑 곶감 타래(짚끈에 꿴 주홍빛 주름 원반), 초가·돌담·외양간,
  눈 덮인 겨울 산, 도둑의 빈 고삐.
- 아이 안전: 위협 없음, 추격은 우스개. 아기 얼굴은 엄마 품에서만.
- 레이어 시범: 인물(tiger·thief·mother_baby) / 소품(gotgam) /
  장소(yard·barn·room) / 배경(night_bg) 8자산. 호랑이는 해와 달에서
  검증된 민화 호랑이 규격을 물려받는다.
