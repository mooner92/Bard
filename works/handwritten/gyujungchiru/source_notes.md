# 규중칠우쟁론기 — 원전 근거 (작자 미상 내간체 수필, 위키문헌 전문)

원문 확보: works/sources/gyujungchiru_ko.txt (6,469자)

- 칠우의 이름(원문): 척부인(자·尺), 교두각시(가위), 세요각시(바늘),
  청홍흑백각시(실), 감토할미(골무), 인화부인(인두), 울랑자(다리미).
- 서사: 규중 부인이 낮잠 든 사이 일곱이 바느질 공을 서로 다툼 → 부인이
  깨어 "공은 사람에게 있다" 꾸짖음 → 칠우가 저마다의 설움(찔리고 데이고
  닳는)을 하소연 → 부인이 노해 내치려 하자 감토할미가 사죄 → 부인이
  감동해 감토할미를 각별히 아낌.
- 각색: 다툼은 뽐내는 '자세'로(자가 곧추서고, 가위가 날을 벌리고), 얼굴을
  그리지 않는 의인화 — 사물의 몸짓만으로 성격을 낸다(불쾌한 골짜기 회피).
- 유보(withheld): 감토할미가 받은 각별한 총애.
- 화풍: 책가도(chaekgeori) 정물풍 — 규방 소품의 품격.
