# 십오 소년 표류기 — 원전 근거

판본: Jules Verne, *Deux Ans de Vacances*(1888). 영역본 *Two Years' Vacation*.

- 오클랜드의 기숙학교 소년 열다섯이 방학 항해를 앞두고 스쿠너 슬라우기호에 오른다. 밤사이 계류줄이 풀려 어른 하나 없이 바다로 떠밀리고, 폭풍이 돛을 찢는다. 브리앙(13, 프랑스)이 키를 잡는다. 배는 무인도 모래톱에 얹히고 소년들은 짐을 뭍으로 나른다.
- 섬 한가운데 바위에 올라 사방이 바다임을 확인한다(원작의 정찰). 먼저 표류했던 프랑스인 보두앵이 남긴 동굴과 손으로 그린 섬 지도를 찾아 그곳을 살림터로 삼는다.
- 투표로 대장을 뽑는다(첫해 고든, 이듬해 브리앙). 겨울을 동굴에서 나고, 봄에 도니팬 무리가 갈라져 나간다. 폭풍 뒤 해변에 보트가 밀려온다.
- withheld: 보트를 타고 온 사람들의 정체(세번호의 케이트와 에번스, 그리고 월스턴 일당)와 소년들이 배를 얻어 돌아가는 마지막.
- 그림 규칙: 배역은 전부 소년이므로 'man'·'grown man' 을 한 낱말도 쓰지 않는다(올리버 트위스트 S8 에서 "a man's coat" 가 어른을 세웠다). 길·바다는 'packed earth'·'open sea' 로 시대를 못박고, 하늘은 cloud 대신 'low grey sky'(구조·지형 낱말은 자산에 있는 island·sea·cave 만 쓴다).
