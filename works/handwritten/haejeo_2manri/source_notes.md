# 해저 2만리 — 원전 근거

판본: Jules Verne, *Vingt mille lieues sous les mers*(1870).

- 1866년 바다 괴물 소문, 아로낙스 교수가 링컨호에 올라 추적, 충돌 뒤 바다에 빠져 노틸러스의 강철 등판 위에 오른다. 네모 선장의 살롱(책·표본장·오르간·큰 둥근 창), 잠수복으로 걷는 바다 밑 숲, 거대한 진주, 남극 얼음에 갇힘, 거대한 오징어, 노르웨이 앞바다의 소용돌이(마엘스트롬)와 보트 탈출.
- withheld: 네모 선장의 내력과 소용돌이 뒤의 결말.
- 그림 규칙: 'forest'·'sea' 는 자산(seabed·frigate)에 넣어 실물화. 'cloud' 는 자산에 없으므로 모래 먼지는 'puff', 하늘은 'sky's edge' 로. 원작의 오징어 싸움·산호 무덤은 아이들 영상이라 창밖의 오징어 한 컷으로만. 잠수복 컷은 얼굴이 안 보이므로 자산 aronnax 를 빼고 diving_suit 만. 팔레트에 붉은색 없음.
