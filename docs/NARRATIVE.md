# 서사 설계 — 30~45초 책 쇼츠가 지루해지지 않는 법

"문법적으로 완벽한데 지루한 대본"이 하네스를 통과하는 문제를 겪고 진행한 조사의 정리.
결론은 하네스에 **서사 검증층**으로 구현돼 있다 (`scripts/write_script.py`의 `narrative_issues()`).

## 1. 실패 진단 — 왜 줄거리 요약은 죽는가

초기 모비딕 대본의 계량: 6문장에 **등장인물 5명**, **인과·역접 접속사 0개**, **반전 0개**,
**문장 길이 30~33자 균일**, **유보된 정보 0개**. 모든 사건이 일어난 순서대로 서술되므로
시청자가 다음 문장을 기다릴 이유가 한 번도 생기지 않는다. "몰입"은 미해결 질문의 하류다.

| 실패 모드 | 증상 |
|---|---|
| 정지 화면 오프닝 | S1이 "누가 어디 서 있다" — 사건도 질문도 없음 |
| "그리고 다음엔" 사슬 | 문장 간 인과 없음, 긴장의 고저 없음 |
| 인물 과적 | 30초에 이름 5개 — 아무도 기억 못 함 |
| 절정 평탄화 | 침몰이 오프닝과 같은 무게·같은 리듬의 한 문장 |
| 추상 결론 | "집착과 불가해함" — 시청자가 내릴 결론을 대신 말해버림 |

## 2. 근거 (등급 표시)

- **정보격차 이론** (Loewenstein 1994, *Psych Bulletin* — 동료심사, 광범위 재현):
  호기심은 "지식의 틈을 인지할 때 생기는 결핍감". 본 설계의 이론적 기반.
  ⚠️ 자이가르닉 효과는 2025년 메타분석(Nature HSSC)에서 기억 이점이 **반증**됨 — 기대지 말 것.
- **이야기형 > 논증형** (Coker & Flight, *JRIM* 15(4), N=273 — 동료심사): 구체적 사건이
  주제 단언을 이긴다.
- **스포일러는 용량 문제** (Leavitt & Christenfeld 2011 vs 반박 연구들): 짧은 스포일러는
  이해를 돕고, 긴 재서술은 해친다. 30초는 구조적으로 "짧은 쪽" →
  **사건은 스포하고, 이유·주체는 감춘다.**
- **but/therefore 규칙** (Trey Parker & Matt Stone, NYU 강연): "그리고 다음엔"으로 이어지는
  비트는 죽어 있고, "그런데/그래서"로 이어지는 비트는 전진한다. 삽입 강제가 아니라 진단 도구.
- **리듬** (Gary Provost): 같은 길이의 문장 연속 = 단조. 짧은 문장 하나가 음악을 만든다.
- **내레이션 방식이 몰입의 최강 예측 인자** (SAGE Open, N=537, PLS-SEM): 다성(多聲) 낭독이
  단일 낭독을 이김 → **인용 대사 1개 = 목소리 변화 = 측정된 레버.**
- **VVSA(Viewed vs Swiped Away)가 핵심 지표** (Galloway/Gileta, 쇼츠 5,400개·33억 뷰 분석):
  상위 채널 70~90%. 2025-03-31부터 **쇼츠 루프 재생이 새 조회수로 집계** → S1↔마지막 문장
  루프백은 기계적 이득.
- ⚠️ 이 분야에 떠도는 정밀한 퍼센트 수치("훅 유형별 리텐션 n%")는 대부분 상호 인용하는
  벤더 SEO다. "8초 주의력" 설도 반증된 신화(BBC/WSJ). 수치가 아니라 메커니즘 위에 지을 것.

## 3. 규칙 (기계 검증 가능형)

| ID | 규칙 |
|---|---|
| H1 | S1은 구체 명사 + 동작 동사. 정지 서술어(있다/서다/보이다/디디다/놓이다/펼쳐지다/나타나다) 금지 |
| H2 | S1에 유보 장치(한/어떤/무언가/누군가 또는 무명의 행위자) — 주인공 이름을 S1에서 밝히지 말 것 |
| C1 | 문장 전환 5곳 중 인과·역접 표지 ≥2 (그래서/결국/그러자/그런데/하지만/사실/정작/오히려), 나열 접속 ≤1 |
| C2 | 문장 길이 표준편차 ≥4.0, ≤24자 펀치라인 ≥1 (총량은 목표 길이에 맞춤) |
| Q1 | 인용 대사 정확히 1개, 중간 문장(S2~S(n-2))에, 내부 ≤14자, 구어여야 함 |
| E1 | 추상명사(집착·운명·본질·진리·불가해·실존·소외…)는 전반부 금지, 후반부는 구체 명사 동반 시 1회만 |
| A2 | 이름 있는 인물 ≤2명 |
| A7 | 메타 요약 어휘 금지 (상징한다/그린다/보여준다/담고 있다/명작/걸작) |
| X1 | 마지막 문장 = **[미해결 질문] + "…는 소설 X에서 만날 수 있습니다"** (라벨이 아니라 열린 고리) |
| X2 | 마지막 문장이 S1과 내용 토큰 ≥1개 공유 (루프백) |

한국어 반전 표지 실전 목록: **그런데, 하지만, 그러나, 사실(은), 정작, 오히려, 결국, 그러자, 그때**.
겹침 강조형 "**그런데 사실**"이 실전 워크호스.

## 4. 재작성 예시 (모비딕, 검증 통과형)

**정보격차형 + 금화 스파인 (1순위 테스트):**
```
S1 에이해브 선장이 돛대에 금화 한 닢을 못으로 박습니다.
S2 "흰 고래를 먼저 보는 자의 것이다." 선원들이 술렁이죠.
S3 흰 고래에게 뜯긴 한쪽 다리, 그 자리에 박힌 고래뼈 의족.
S4 그래서 배는 사흘 밤낮을 오직 그 흰 그림자만 쫓습니다.
S5 결국 사흘째 밤, 배도 선원도 모두 바다 밑으로 사라졌죠.
S6 한 사람만 살아남은 이유는 소설 모비딕에서 만날 수 있습니다.
```
인물 1명. 인과 사슬: 금화(왜?) → 뜯긴 다리(그래서였구나) → **그래서** 추격 → **결국** 침몰
→ 그런데 한 명이 살았다(왜?) → 책으로. 인용 1개 = 목소리 변화.

**단일 사물 스파인 (관, 2순위 — 천장 높음):** 퀴퀘그가 자기 관을 짠다 → 열병이 낫자 빈 관만
남는다 → 그 관이 유일한 생존자를 띄운다 → "관이 왜 그를 살렸는지는 소설에서".
원작의 진짜 기적을 스파인으로 쓰는 구성.

## 5. 한국어 낭독 관례

- 존댓말 고정 (전 북튜브 공통: 너진똑·겨울서점·고전책방·5분뚝딱철학). 음슴체·반말 금지
- 속도: 유튜브 표준 400자/분 = **6.67자/초**. 문장 30자 ≈ 4.5초
- 어미 계열 교차(합니다체/구어체/명사종결)는 유지 — 좋은 낭독 관례에 부합
- 참고 채널: 고전책방(@go_readclassic — "부담스러운 고전을 15분으로", 니치 최근접),
  너진똑("책의 부속품이 아니라 책을 소재로 한 별개의 완성된 콘텐츠")
- CTA 원칙: "부탁이 아니라 이유를 함께" — 미해결 질문이 그 이유가 된다

## 6. 남은 진실

서사 구조가 쇼츠 완주율에 미치는 효과를 격리한 엄밀한 연구는 **존재하지 않는다.**
우리는 생성기 + 검증기 + 고정 포맷을 갖고 있으므로, 구조만 바꾼 A/B(v3.2 vs 신구조)를
직접 돌려 초당 리텐션·VVSA를 기록하면 공개된 어떤 자료보다 나은 데이터가 된다.
