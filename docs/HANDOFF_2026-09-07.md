## 4. 검수·전송 절차

```bash
S=/tmp/claude-scratch; mkdir -p $S; W=<work>
# kf 3·8·15장 시점: 320×568 로 축소해 모두 읽는다
for i in 1 2 3; do f=$(ls output/${W}_kf/night_s${i}_*.png | head -1); ffmpeg -nostdin -y -loglevel error -i "$f" -vf scale=320:568 $S/k$i.jpg; done
# 발행 뒤: 클립 15개 중간 프레임 전부(첫 프레임이 kf 와 같은 구도인지도 본다 — 다르면 크롭 값부터 확인)
for i in $(seq 1 15); do f=$(ls output/${W}_i2v/night_s${i}_*.mp4 | head -1); d=$(ffprobe -v error -show_entries format=duration -of csv=p=0 "$f"); m=$(python3 -c "print($d*0.5)"); ffmpeg -nostdin -y -loglevel error -ss "$m" -i "$f" -frames:v 1 -vf scale=150:267 $S/c$i.jpg; done
# 전송본
ffmpeg -nostdin -y -loglevel error -i output/$W/final_night.mp4 -c:v libx264 -crf 30 -preset medium -c:a aac -b:a 96k -movflags +faststart $S/$W.mp4
```

SendUserFile 캡션: 제목(작가·연도), 초, 15컷, 톤, 계절, 줄거리 한 줄(결말 유보), 수리 컷 수, 출처.
중복 렌더 `night_s{i}_00002_.png` 가 생기면(정지 후 ComfyUI 가 마저 저장) 00001 을 검토하고 00002 는 지운다.
정지 직후 옛 프롬프트로 저장된 kf(예: 정지 시각 이후 mtime 의 다음 컷)는 지워야 재사용되지 않는다.
