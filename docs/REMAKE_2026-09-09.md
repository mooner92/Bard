# 옛 포맷 74편 재제작 프로그램 (2026-09-09 시작)

사용자 지시: "모비딕 같은 40초 영상들(프롬프트 빈약하던 시절)은 다 다시 만들어야 한다.
지금은 70초 언저리 나오고 프롬프트 규칙도 잘되어 있다. 빈약했던 영상들 다시 만들고 가자."

## 대상

발행작 122편 중 **8컷 옛 포맷 73편 + 모비딕(14컷, v1 원고)** = 74편. 15컷 규격 49편은
09-08~09 v2 리마스터로 끝났다(HANDOFF §15). 작업 순서와 상태는 `works/remake_order.txt`
(`work \t 제목 \t 묶음 \t 상태`).

## 흐름 (편당)

1. **원고** — `works/handwritten/<work>/` 에 현행 규격으로 새로 쓴다(옛 원고는 스크래치
   `remake_old/<work>/` 로 백업).
   - `assets/*.md` 인물·소품·장소·배경 (PROMPTCRAFT §8: spec 한 문장 + 상세, kind 별 상한)
   - `treatment.json` — logline·destination·protagonist·setting·prompt_style "detail"·
     assets_dir·anchor·palette·beats[15]·withheld. 비트마다 cast(z 순서)·refs []·beat·
     visual(영어 700~1000자)·motion(300~400자, 동작 하나·지속형·holds still·camera 절)
   - `narration_night.json` — `"author": "hand"`, 15문장(13 몸통 + 질문 + 마무리),
     v2 말투(합니다/해요/지요/명사 종결 섞기, 한 말투 ≤6, 3연속 금지), 대사 1~2마디
     (`[역할·감정] "…"`, 대사 ≤16자, 그 문장 지문 ≤26자, 느린 목소리(짐승·할아버지·남자)면 ≤18자),
     이어짐 낱말, 끝에서 둘째는 질문, 마지막은 `destination` 문구. 작가·수상·출판 메타 금지.
   - `source_notes.md` — 원전 근거(판본·인물 묘사 대목) 짧게.
2. **검사·투입** — `scripts/remake_queue.sh <work> "<화풍>" [톤]`: 비트 수=문장 수, cast 자산
   존재, 관문(gate_script), check_craft 무결(트리트먼트 지적까지 0) → treatment/narration
   touch(신선도: 옛 kf·클립·tts·final 을 배치가 버림) → `works/queue.txt` 에 한 줄.
3. **렌더** — `aivideo-night.timer`(매시 :15, DEV_247=1 24시간)가 큐를 보고 `night_batch_v2.sh`
   를 띄운다. ComfyUI 는 다른 프로젝트와 공유 — `comfy_wait.py` 가 남의 **대기** 작업이 1건
   이하일 때만 우리 작업을 넣어 한 작업씩 번갈아 돈다(빌 때까지 기다리면 굶는다 — 09-09 실측
   infog 연속 제출).
4. **검수** — 배치 자가점검(review_output) + 키프레임 눈검사(글자·간판·이름표·빈 판·정체 결속)
   + 배속(감속 1.5배 초과 컷은 `patch_sentence.sh` 로 그 문장만 재합성).
5. **발행·전송** — 같은 work id 로 재발행되므로 사이트가 갈아탄다. 540p 전송본을 사용자에게
   묶음으로 보낸다.

## 소요 실측 (모순 09-08, GPU 독점)

| 단계 | 소요 |
|---|---|
| 키프레임 1장 | 약 4~5분 (15장 ≈ 40~70분) |
| 클립 1개 (WAN I2V 117프레임) | 약 13분 (15개 ≈ 3시간 15분) |
| 편당 | **약 4시간 20분** |

74편 ≈ 320 GPU 시간 ≈ 13일(독점). 다른 프로젝트와 1:1 로 번갈면 2배 안팎. 원고 작성은
편당 15~20분이라 GPU 가 병목 — 원고는 큐보다 4~6편 앞서 쓰면 충분하다.

## 순서 (묶음)

A 사용자 지명 + 한국 근대 단편(도서관 독자층) → B 한국 고전 설화·소설 → C 세계 아동 고전 →
D 세계 성인 고전. 상세는 `works/remake_order.txt`.

## 추적

`works/remake_order.txt` 의 상태 열: `-` 대기 · `원고` 원고 완료 · `큐` 큐 투입 · `렌더` 렌더 중 ·
`검수` 검수 중 · `완료` 발행·전송. 갱신은 `scripts/remake_queue.sh`(큐) 와 손(그 밖).
