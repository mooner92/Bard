## 3. 사이드카 kf 재생성 (정확한 명령)

도구는 이 세션 임시 폴더에서 저장소로 옮겨 두었다: `scripts/sidecar/mkprompt.sh`(배치와 같은 방식으로 이미지 프롬프트 생성), `scripts/sidecar/neg_base.txt`(기본 부정어). 이번 세션의 프롬프트·부정어 실물은 `logs/review/remake_todo/sidecar_prompts/`(예: `pti_2.txt`, `neg_ti2.txt`).

```bash
S=/path/to/scratch   # 아무 임시 폴더
# 1) 두 사본을 같이 고친다: works/handwritten/<w>/treatment.json 과 output/<w>/treatment.json (+ assets/*.md)
#    mtime 은 os.utime 으로 보존(원고가 그림보다 새것이면 배치가 prev/ 로 보내고 다시 굽는다)
# 2) 프롬프트
bash scripts/sidecar/mkprompt.sh <w> <N> > $S/p.txt
echo "<컷별 부정어>, $(cat scripts/sidecar/neg_base.txt)" > $S/neg.txt
# 3) 제출(백그라운드; 프로세스가 죽어도 ComfyUI 큐의 작업은 살아서 파일이 떨어진다)
nohup venv/bin/python scripts/gen_keyframe.py --seed <새 씨앗> --prefix "<w>_kf/alt_sN" \
  --prompt "$(cat $S/p.txt)" --negative "$(cat $S/neg.txt)" > $S/alt.log 2>&1 &
# 4) 도착은 Monitor 로: output/<w>_kf/alt_sN_00001_.png 생김 또는 큐에서 사라짐
# 5) 취소(내 것만): pending 은 POST /queue {"delete":[id]}, running 은 POST /interrupt
```
씨앗은 2000번대를 순서대로 썼다(마지막 2400). 프롬프트에 금지어(nobody/no one/empty of/nothing else, 동음이의어)가 남았는지 `grep -oiE` 로 확인하고 낸다.

**pkill 주의**(메모리 `pkill-self-match.md`): 내 Bash 명령줄 안의 어떤 문자열도 `pgrep -f` 에 걸려 셸이 죽는다. 폴러를 죽일 때는 `for pid in $(pgrep -f gen_keyframe.py); do case "$(cat /proc/$pid/comm)" in python*) …grep cmdline…; kill;; esac; done` 처럼 **comm 이 python 인 것만** 고르고, 대상 문자열은 `P="alt_s""2"` 로 쪼갠다.
